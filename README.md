# Super-Exponential Growth in the Agentic Era

The site at [superexponentialgrowth.fun](https://superexponentialgrowth.fun) and the working paper behind it, by Josu San Martin.

| File | What it is |
| --- | --- |
| `index.html` | The site: one formula, a slider for every letter, and the chart it draws. Self-contained. |
| `paper.pdf` | The working paper (November 2026). |
| `formula.txt` | The formula the site runs, as about 60 lines of JavaScript. |
| `baseline.csv` | The baseline path of the one-stock formula, 2026 to 2045, in trillions of 2026 dollars. The full model's path is in the zip. |
| `agentic_growth_v3.py` | The paper's full model (Python, SciPy). `agentic_growth_v3.txt` is the same file, served as text. |
| `super-exponential-growth.zip` | The paper's source, code, data and results. `./run_all.sh` reproduces every number in about a minute. |

A model, not a forecast.
